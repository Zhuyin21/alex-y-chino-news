# Sound-effect sources

Original clips picked by the producer on Pixabay (pixabay.com/sound-effects, Pixabay Content License: free for commercial and non-commercial use, no attribution required), downloaded Nov 18, 2026. `pipeline/sfx_mix.py` cuts and mixes them into `assets/sfx/<name>.mp3`; the ping, glitch and space beeps in the Tech Thursday clips are synthesized in that script.

To add variety: add a new source here, add a recipe in `sfx_mix.py`, and save it as `<name>-2.mp3`, `<name>-3.mp3`…: the build rotates variants every week.
